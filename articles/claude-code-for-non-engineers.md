# 1. Claudeって何がそんなにいいの？

## コードは書きません

「Claude Code」という名前を見て引いた方、ちょっと待ってください。

やることはシンプルです。
- **あなた：** 日本語で「〇〇して」と頼む
- **Claude：** 裏でコードを書いて実行して、結果を返してくれる

ChatGPTを使ったことがある方なら、違いはひとつだけ覚えておけば大丈夫です。ChatGPTは「答えてくれる」。Claudeは「答えて、さらに実行してくれる」。

たとえばChatGPTだと「こんなメール文面はどうですか？」とテキストが返ってきて、自分でコピペしてGmailに貼ります。Claudeの場合は「Gmailの下書きに保存しておきました」まで勝手にやってくれる。この**最後のひと手間がなくなる**のが、使ってみると想像以上にデカいです。

:::message alert
**🔒 会社で使う前に、必ず情シスの許可を取ってください**

Claudeは外部のクラウドサービスです。業務データ（メール、ファイル、顧客情報など）を扱うなら、会社のセキュリティルールに沿う必要があります。

**導入前に確認すべきこと：**
- 自社のAIツール利用ポリシーにClaudeが該当するか
- 外部サービスへのOAuth連携（Gmail、Drive等）が許可されているか
- 機密情報の取り扱いルール（Claudeに渡してよい/いけない情報の線引き）
- オプトアウト設定（後述）が必須か

「個人の判断で勝手に使い始める」のはNGです。まず情シスか上長に「Claude使っていいですか？」と確認してください。会社によってはTeamプランやEnterprise契約で全社導入しているケースもあるので、先に聞いたほうが話が早いこともあります。

# 2. まずはセットアップしよう

## デスクトップアプリを入れよう

Claudeには Web版（claude.ai）、デスクトップアプリ、モバイルの3つの入口がありますが、**基本的にはデスクトップアプリ一択**です。

理由はシンプルで、Web版やモバイルでは使えない**Cowork**という機能がアプリにはあるから。Coworkは「〇〇して」と頼むと、ファイルを作ったりデータを整理したりといった作業を勝手に進めてくれます。これがビジネス職にとっての本丸。

アプリには「Chat」「Cowork」「Code」の3タブがありますが、使うのは**ChatとCoworkだけ**。Codeは無視でOKです。

![Web版 vs デスクトップアプリ比較](/images/03_web_vs_app.svg)

## セットアップの流れ

手順は公式ヘルプや他の記事が詳しいので、ここではざっくりだけ。

1. **アカウント作成** → [claude.ai](https://claude.ai) で登録
2. **プラン選択**
3. **デスクトップアプリをインストール** → [claude.com/download](https://claude.com/download) からダウンロード
4. **サインイン** → Web版と同じアカウントでログイン

:::details 📎 セットアップの詳細手順はこちら
手順を画像つきで知りたい方は、以下の記事がわかりやすいです：
- [Zenken AI「Claude Coworkとは？始め方と活用法」](https://ai.zenken.co.jp/post/claude-cowork-howto/) ── Coworkの導入からWindowsの開発者モード設定まで丁寧
- [AQUA「Claude Coworkとは？非エンジニア向け徹底解説」](https://www.aquallc.jp/2026/01/23/claude-cowork-guide/) ── プラン比較・使用量の仕組みまで網羅
:::

:::message alert
**⚠️ 対応環境の注意**
- **Mac：** Apple Silicon（M1以降）のみCowork対応。Intel MacはChatのみ
- **Windows：** x64のみ。ARM版は非対応。Coworkには「開発者モード」のオンが必要（2026年3月時点）
  - ⚠️ 開発者モードの有効化は**個人の判断で行わないでください**。必ず上長または情シスに確認のうえ設定してください
:::

### 🔒 セキュリティ設定（必須）

業務で使うなら、これだけは最初にやっておいてください。

#### オプトアウト設定（学習データへの利用拒否）

2025年8月の規約改定で、デフォルトだと会話データがAIの学習に使われるようになっています。業務利用するなら**必ずオフ**にしておきましょう。

1. 設定（Settings）を開く
2. 「プライバシー」を選択
3. **「Claudeの改善にご協力ください（Help improve Claude）」をオフ**にする

Proプラン以上はデフォルトでオフの場合もありますが、**自分の目で確認してください**。オフにしても機能は一切変わりません。

<!-- 📸 ここに実際のオプトアウト設定画面のスクリーンショットを貼る -->

#### その他のセキュリティ注意事項

- **機密情報の入力は慎重に：** 顧客の個人情報、未公開の財務データ、社外秘資料などをClaudeに渡す場合は、社内ポリシーを確認
- **Coworkのフォルダアクセス：** Coworkは指定したフォルダしか触れない設計ですが、機密フォルダは指定しないこと
- **Claude in Chromeの権限：** ブラウザ拡張を使う場合、パスワードや金融取引の操作は絶対にさせない
- **全社導入を検討する場合：** SSO・監査ログ等が整ったEnterpriseプランもあります。詳しくは情シスへ

# 3. 普段のサービスとつなごう

## コネクタって何？

Claudeを普段使ってるサービス（Gmail、カレンダー、Drive等）とつなぐ機能です。つなぐと、Claudeがメールやファイルを直接読めるようになります。いちいちコピペしなくてよくなるだけで、使い心地が全然違います。

## つなぎ方（30秒で終わる）

1. 設定 > Connectors →「Browse connectors」
2. つなぎたいサービスを選ぶ
3. 「許可する」をクリック

技術的な設定は何もいりません。

:::message alert
**🔒 コネクタ接続前のセキュリティ確認**
Gmail・Drive等をつなぐ = 会社のデータへの外部アクセスを許可すること。**必ず情シスに確認済みの状態で行ってください。** 会社のセキュリティポリシーで外部OAuth連携が制限されている場合、個人の判断でつなぐとトラブルの元になります。
:::

## まずつなぐべき3つ

**① Gmail** ── メールの検索・読み取り・下書き作成。「先週のクライアントメールまとめて」が一声でできる
**② Google Calendar** ── 予定確認・空き時間の提案。「来週の空いてる時間教えて」が一瞬
**③ Google Drive** ── ファイルの検索・取得。「先月の議事録読んで要点まとめて」が可能に

余裕があれば：Slack、Notion、Asana/Linear/Jiraなど主要なビジネスツールはほぼ対応しています。

![コネクタ接続ステップ](/images/05_connectors.svg)

## つなぐとこう変わる

**Before（いつもの月曜朝）：**
Gmail確認→Slack確認→カレンダー確認→Drive検索→Notion更新、5アプリ行き来で **45分**

**After（Claude＋コネクタ）：**
「週末の未読メール、Slackの重要スレッド、今週のカレンダーをまとめて」 → **5分**

正直、この体験だけでも月$20の元は取れます。

# 4. 最初の1個を作ってみよう

ここまでで環境は整いました。さっそく動かしてみましょう。

## お題：歓迎会の招待メール

> 来週金曜の19時から、渋谷のイタリアンで新メンバーの歓迎会をやる。部署メンバーに招待メールを送りたい。

Claudeのチャット欄にこう打つだけです：


```
来週金曜の19時から歓迎会をやります。
場所：渋谷のトラットリア・ボーノ（住所：渋谷区道玄坂1-2-3）
目的：新メンバーの佐藤さんの歓迎
参加者：プロダクト部のメンバー全員

Gmailで招待メールの下書きを作ってください。
カジュアルなトーンで、出欠の返信を求める文面で。
```
Claudeが勝手にメールを送ることはないので、安心してください。

Claudeは①Gmailを開く → ②カジュアルな招待文を作成 → ③下書きに保存、まで一気にやってくれます。

あとは下書きを開いて、内容を確認して送信ボタンを押すだけです。

![招待メール作成フロー](/images/07_tutorial_flow.svg)

## うまくいかない時

- **文面がイマイチ** → 「もう少しフォーマルにして」「絵文字入れて」と追加指示するだけ
- **下書きが作られない** → コネクタの接続状態を確認（設定 > Connectors）
- **途中で止まった** → 新しいチャットでやり直す。これで大体解決します

:::details 💡 やりがちな失敗3つ
**① 指示が曖昧すぎる**
✕「いい感じのメール作って」→ 何を誰にどんなトーンで、がわからない
◎「マーケ部全員に、カジュアルなトーンで、出欠返信を求める歓迎会の招待」→ 具体的なほど結果がいい

**② 1つのチャットで色々やりすぎ**
メール作成のあとに資料整理もデータ分析も……とやると、Claudeの頭が混雑して精度が落ちます。タスクが変わったら新しいチャットを始める。これだけで体験がだいぶ変わります。

**③ 確認しないで進む**
Claudeは優秀ですが完璧じゃないです。特にメールの宛先と日時は、送信前に必ず自分の目でチェックしてください！
:::


ちなみに今回は省略しましたが、「Googleカレンダーにも歓迎会の予定を登録して」と一言添えるだけで、カレンダー登録までやってくれます。

メール作成、カレンダー登録、出欠管理……全部ひとつのチャットで完結する。これがChatGPTとの最大の違いで、Claudeは「答えて、さらに実行してくれる」。この強みを一度体験すると、もう戻れなくなります。

# 5. ここから先が本番 ── もっと使いこなすために

## ChatとCoworkの使い分け

ここまではChatタブだけで試しました。でもClaudeの本領は、もうひとつの「Cowork」タブにあります。

ざっくり言うと：
- **Chat** = 会話。「これどう思う？」「要約して」みたいな1問1答
- **Cowork** = 作業。「このフォルダ整理して」「Excelにまとめて」みたいな自律的なタスク処理

迷ったら「すぐ答えが欲しい→Chat」「ファイルを作りたい→Cowork」で分けてください。

![Chat vs Cowork使い分け](/images/08_chat_vs_cowork.svg)

## もっと活用できる機能たち

ここまで紹介した以外にも、Claudeにはまだまだ便利な機能があります。全部覚える必要はありません。知らなくても、やりたいことをClaudeに伝えれば答えを示してくれます。

ただ「こういうことができるんだ」と知っているだけで、発想の幅は全然違います。
気になったものがあれば、参考記事を覗いてみてください。それが「次にやりたいこと」になるはずです。
